# Dependency review — 2026-10-23

This review selects eight maintenance dependencies with concrete benefits and keeps migrations with unresolved compatibility or regression risks separate. Security remediation is in [PR #32326](https://github.com/stablyai/orca/pull/32326); this maintenance PR builds on it.

## Coverage and method

- Inventoried all **19 npm manifests**, **298 external direct declarations**, and **209 distinct package names**. Queried npm metadata for every name: latest tags, publication dates, repository, engines, peers, deprecations, integrity and available provenance. [Every package and decision](npm-inventory.md) is recorded, including packages left unchanged.
- Audited all five pnpm lockfiles using the repository's `check:dependencies` gate. The initial graph contained **4,136 package entries** across desktop, mobile, cloud, docs and audit tools; these are lockfile entries, not distinct packages. The gate also verifies the existing advisory exceptions against their committed patch hashes.
- Read upstream releases, relevant source changes, compatibility notes and issue reports for proposed updates and higher-risk alternatives. Registry coverage is exhaustive for direct npm dependencies; upstream source/issue review is focused on update candidates, rather than every commit of every transitive repository.
- Queried OSV for **167 locked non-JavaScript entries**: 34 Rust, 131 Ruby/platform entries and 2 Python requirements. No advisories were returned. Requeried platform-suffixed ffi entries using upstream version 1.17.4. Reviewed native manifests, Android test/WebView pins, release tooling and all **15 external GitHub Action repositories**. [Native and CI inventory](native-and-ci-inventory.md).
- Began at `8d94ed06570`. Main advanced to `d9dc87b2fb0` during the review and independently upgraded Bun, tsrs, DOMPurify and Next. The final branch incorporates that main and the security prerequisite; the inventory distinguishes initial and selected versions.

## Security result and boundaries

The combined branches clear all unexcepted findings from the five-lockfile gate. The only accepted findings remain the existing hash-verified `braces@3.0.3` and `node-forge@1.4.0` patches. Upstream has not published replacements for those patched versions. Keep the reviewed patches and exceptions.

PR #32326 also fixes Electron's compromised-intermediate certificate advisory, which was absent from the npm audit response. It preserves the separately verified Node runtime assets and hashes. A clean registry scan alone therefore does not establish runtime security.

The OSV checks cover the committed Rust/Ruby/Python versions, not downloaded tool binaries, container OS packages or a newly resolved CocoaPods/Maven graph. Android WebView 1.14.0 is deliberately synchronized with the patched React Native WebView package. Container base/runtime digests and release signing pins stay unchanged. Native device builds, macOS/Windows packaging and complete Electron application integration are CI/platform validation responsibilities.

## Validation

Run with `ORCA_BACKGROUND_LAUNCH=1`, Node 24 and pinned Bun 1.4.4 on Linux. No user desktop windows are shown or focused.

- All four desktop typecheck projects pass; mobile typecheck passes after the existing generated-engine postinstall; cloud build and all cloud typechecks pass.
- Relay suite: **1,279 passed**, 201 skipped (database/service-dependent cases).
- Selected renderer, cookie policy, URL classification and Vitest Node worker transport tests: **954 passed across 88 files**. Cookie suite on the isolated virtual display: **248 passed across 30 files**. An earlier parallel virtual-display cleanup failure passed on retry and the full serial rerun.
- Actual mobile Mermaid rendering in Chromium: **4 passed**; 4 WebKit cases excluded because WebKit is not installed locally.
- Shared mobile/desktop dependency versions, Node runtime pins, frozen installs, dependency security and changed-file formatting/lint checks are checked before publication.
- The security prerequisite also ran the complete mobile suite (**11,489 passed**, 6 skipped), docs tests (**18 passed**), the production docs build (**121 pages**) and Chromium hydration/navigation/search checks.
- React Doctor's real changed-file smoke remains a baseline limitation described above; neither its version nor its fixture is changed here. Native-focus and visible-window checks stay on isolated displays or CI.

These checks reduce regression risk; they do not guarantee zero regressions. Package registry and advisory results are a dated snapshot and should be refreshed when merging materially later.
